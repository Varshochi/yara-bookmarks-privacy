# YARA Bookmarks Privacy Policy

Public privacy policy for the **YARA Bookmarks** Chrome extension.

- Policy: [privacy.html](privacy.html)
- Site root: [index.html](index.html)

**Effective date:** September 9, 2026

YARA Bookmarks is local-first. Inbox items, learned rules, settings and related state stay in Chrome extension storage. The extension does not send captured URLs, bookmark data, page titles, selected text, tags, project labels or Inbox content to the developer or third-party servers.

After GitHub Pages is enabled on this repository, the public URLs are:

- `https://varshochi.github.io/yara-bookmarks-privacy/`
- `https://varshochi.github.io/yara-bookmarks-privacy/privacy.html`

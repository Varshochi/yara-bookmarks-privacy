YARA Bookmarks Privacy Policy

Effective date: September 9, 2026

YARA Bookmarks is a Chrome extension for organizing Chrome bookmarks and capturing useful web content into a local YARA Inbox.

Data handled

  • Chrome bookmark titles, URLs, folders and bookmark IDs
  • URLs and page titles explicitly sent to YARA Inbox
  • Link text or selected text explicitly captured by the user
  • Locally generated categories, project labels, tags, learned sorting rules, canonical folder IDs, Inbox status and extension settings

How data is used

  • Organize Chrome bookmarks
  • Learn user-directed bookmark placement
  • Classify and organize YARA Inbox items
  • Search, filter, edit, mark Done, Archive, Delete or Promote items
  • Store extension settings and local state

Local-first

Inbox items, learned rules, settings and related state are stored locally using Chrome extension storage. No account or cloud backend is required.

Data transmission

YARA Bookmarks does not send captured URLs, bookmark data, page titles, selected text, tags, project labels or Inbox content to the developer or third-party servers.

No sale, ads or analytics

  • No sale of user data
  • No personalized advertising
  • No analytics
  • No telemetry
  • No tracking pixels
  • No remote AI API
  • No remotely hosted executable code

Permissions

  • bookmarks — read, create, move and organize bookmarks and folders
  • storage — save local settings, learned rules, canonical folder IDs and YARA Inbox data
  • contextMenus — provide the user-triggered “Send to YARA Inbox” right-click action

User control

Users can delete YARA Inbox items and Chrome bookmarks. Removing the extension removes its local extension storage according to Chrome behavior.

Limited use

Data is used only for the disclosed bookmark organization and YARA Inbox features.

This policy applies to the YARA Bookmarks Chrome extension. The same document is published at privacy.html.
